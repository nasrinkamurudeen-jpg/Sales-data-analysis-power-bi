# 📊 Sales Report Dashboard (Power BI)

## 📌 Project Overview
This project is a **Power BI Sales Dashboard** that provides insights into sales performance across different regions, categories, and time periods. It helps in understanding trends, profitability, and customer-level performance.

---

## 🖼️ Dashboard Preview

![Sales Dashboard](Screenshot%202026-05-30%20111638.png)

---

## 📊 Key Insights

- 📍 **Sales by Region** – Compare performance across West, East, Central, and South
- 🛒 **Sales by Category** – Technology, Furniture, and Office Supplies
- 💰 **Profit by Sub-Category** – Identify top and low performing products
- 📅 **Monthly Sales Trend** – Track growth and seasonal patterns
- 👥 **Customer Sales Data** – Analyze top customers by revenue

---

## 🧩 Features

- Interactive filters (Region, City)
- Dynamic visuals (Bar Chart, Pie Chart, Line Chart, Funnel Chart)
- Drill-down analysis
- Clean and user-friendly UI
